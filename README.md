# DATAxperience: Ciencia de Datos en Acción

## Análisis del cumplimiento de entregas en una Central de Mezclas Farmacéuticas

### Integrantes

- Laura Catalina Mejia
- Juan Pablo Castañeda

## Descripción del proyecto

Este proyecto aplica herramientas de ciencia de datos al análisis del
cumplimiento de entregas en una Central de Mezclas Farmacéuticas.

El propósito es transformar registros operativos en información útil
para identificar tendencias, oportunidades de mejora y apoyar la toma
de decisiones basada en datos.

## Objetivo

Analizar el comportamiento del cumplimiento de las entregas para
identificar tendencias, diferencias entre servicios y oportunidades
de mejora.

## Pregunta de negocio

¿Qué servicios presentan mayores oportunidades de mejora en el
cumplimiento de las entregas y cómo ha evolucionado este indicador
durante el período analizado?

## Metodología

El proyecto incluye:

- Preparación y limpieza de datos.
- Análisis exploratorio.
- Visualización de indicadores.
- Identificación de oportunidades de mejora.
- Regresión lineal.
- Interpretación de resultados.
- Propuesta de aplicación profesional.

## Modelo predictivo

Se utilizó un modelo de regresión lineal para analizar la tendencia
del porcentaje de cumplimiento a través del período estudiado.

El modelo obtenido presentó:

- Pendiente: 0.1142
- Intercepto: 92.7904
- R²: 0.1479

El resultado evidencia una tendencia positiva del indicador, aunque
el valor de R² indica que el modelo explica una proporción limitada
de la variabilidad observada.

## Aplicación profesional

En el entorno de una Central de Mezclas Farmacéuticas, el análisis
de datos puede utilizarse para identificar servicios con mayores
oportunidades de mejora, priorizar investigaciones de causas,
realizar seguimiento de indicadores y apoyar la toma de decisiones.

La información puede integrarse posteriormente en dashboards para
facilitar el monitoreo continuo del cumplimiento de las entregas.
